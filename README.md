# Сергей Головенькин — сайт ведущего

Готовый адаптивный одностраничный сайт ведущего Сергея Головенькина.

## Концепция

Сайт собран в эстетике современных event-портфолио 2026 года: крупная типографика, акцент на личности ведущего, короткие сильные тексты, живые кадры и видео вместо длинных рекламных описаний. Референсное направление: Zorrova / Андрей Богомолов / Vitaliy Valigura, без копирования их дизайна.

Ключевая фраза: **«Читаю зал, а не сценарий.»**

## Что внутри

- адаптивный hero-блок;
- свадьбы, корпоративы, выпускные и юбилеи;
- раскрывающиеся описания каждого формата;
- 4 видео с предоставленного Google Drive в модальном просмотре;
- динамичная фотогалерея;
- форма проверки даты без отдельного сервера: формирует текст запроса, копирует его и открывает диалог VK;
- телефон и VK Сергея;
- микроанимации и поддержка `prefers-reduced-motion`;
- никаких библиотек, сборщиков и зависимостей.

## Запуск

Проект сделан одним `index.html`, поэтому его можно просто открыть в браузере или положить в корень любого статического хостинга.

Для локального запуска:

```bash
python -m http.server 8080
```
